# unraid-plugins

Community Applications metadata for my Unraid plugins.

- `ca_profile.xml`: maintainer profile shown in Community Applications.
- `plugins/`: one wrapper XML per plugin. Each `PluginURL` must match the `pluginURL` attribute in that plugin's `.plg` exactly.
